# Bootstrap verification record

Date: 13 September 2026. Execution environment: Node.js 22.16.0 on Linux in the build environment. This is a record of tests run, not an independent audit or production-security statement.

## Executed locally

- `npm run check`: syntax-checks all `.mjs` files in source, tests, scripts, experiments and web; confirms no third-party package dependencies.
- `npm test`: 60 tests passed, zero failures/skips/todos at the initial complete bootstrap check. This includes 1,500 generated candidate actions across five seeds and real loopback HTTP failover/login tests.
- `npm run demo`: six repeatable scenarios completed and the industry journal revalidated against its genesis and final checkpoint.
- `npm run build:web`: static viewer and report generated successfully.
- Browser UI smoke: rendered the exact local HTML/CSS/JavaScript with an injected static report, exercised all six scenario controls, and inspected desktop (1366 px) and mobile (390 px) screenshots. No JavaScript errors or horizontal mobile overflow. The environment blocked browser navigation to loopback; HTTP was tested separately through the Node integration suite, not claimed as browser-to-server end-to-end testing.

The suite covers money/raw-material conservation; invalid command atomicity; signature/world/nonce/expiry checks; bounded controller authority; revocation and key rotation; host-bound login; leases/freehold; duplicate asset sale; exact provider pricing; escrow/receipts/levies/default; cold restoration; journal corruption/staleness; founder boundaries; exact release manifests; and bounded declared-source evidence handling.

Full current test output is generated by the commands; do not treat this historical count as a required fixed number after future contributions. Re-run tests on every material change.

## Reproducibility and provenance

No LLM calls, provider keys, database installation or third-party package downloads are required to execute the lab. Deterministic signing fixtures and genesis are deliberately public. Random challenge nonces are confined to the host-authentication adapter; experiment report content and core transitions remain reproducible.

GitHub CI is configured for Node 22/Linux, Node 24/Linux and Node 24/Windows using pinned checkout/setup action revisions. Configuring those jobs is not evidence they passed: check the workflow result for the delivered commit. Repository branch protection and required review rules are not silently installed by this workflow file.

## What was NOT verified

Independent security review, live blockchain execution, adversarial validator quorum, actual paid service delivery, long-term storage availability, private rooms, real-world KYC, production wallet UI, post-quantum security, human economic demand, closed-economy sustainability, real-world reviewer independence, legal liability or licensing approval.

The bootstrap was written and tested by the same assistant. It must not be labelled independently reviewed. The deliberate fake identities mean signatures exercise software correctness, not genuine participant identity or secrecy.
