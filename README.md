# Oatrix

An industrial shared-reality experiment: creation consumes resources; useful contributions can earn rewards; identity and ownership do not belong to a hosting node.

## Bootstrap status

This repository is being initialised with a bounded deterministic laboratory, executable invariants and versioned design decisions. It is **not** a deployed blockchain, a token offering, a production identity service or a promise of permanent hosting.

The initial experiment uses local test identities and resettable settlement units with no real-world value. No model-provider credentials or paid services are required.

## Founding direction

- Participants may authenticate through interchangeable hosts without changing their underlying principal identity.
- Title, physical content bytes, hosting contracts and active deployment locations are separate.
- Leases follow their agreed terms. Freehold ownership is not silently revoked for inactivity.
- Cold backups restore content, not old balances or duplicate scarce resources.
- Production consumes resources and capacity; money is not minted merely because an agent reports work.
- The founder retains disclosed bootstrap intervention until evidence supports handover. The pilot is not advertised as decentralised.
- Bounded deterministic experiments are a valid first test bed; the eventual dominant use case remains open.

Code, tests, operator instructions and the design baseline follow in the bootstrap implementation.
